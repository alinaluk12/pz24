Модуль 2. Логистика рейса

Формула: T = 2L/V × 60 + tп + tр. Объём из Модуля 1 передаётся в поле «Объём груза»; скорость, расстояние и времена погрузки/разгрузки вводятся отдельно.

Модуль 3. Расход топлива

Формулы из справочника: Q = N × q × P / 1000; C = Q × Cт. Масса из Модуля 1 передаётся как справочное значение для связи модулей. Формула расхода топлива рассчитывается по параметрам N, q, P и цене топлива.
